## Spend Elon Musk's Fortune

Bored? Try spending Elon Musk's money.

Developed with JavaScript.

Project Features:

- Used React.js, Context API, CSS & LazyLoading mechanism.

- Fully Mobile Responsive.

- UI/UX based design.

Game Features:

- You own the entire known fortune of Elon Musk ($251 Billion).

- Do your best to finish the money!

### Running Locally

* Clone the repository and run the commands below in a terminal window to setup & run the app.
```
npm install
```
```
npm run start
```
